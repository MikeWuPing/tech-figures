# 交付前核对清单

配图这类东西，**代码不报错不等于图是对的**。下面每一条都是踩过的坑，逐条过。

## 单张图

渲染完 **Read 看一眼**，然后问：

- [ ] 有没有文字**溢出画布**或被裁掉？绝对定位的元素最容易出这事
- [ ] 有没有元素**重叠**？尤其连线穿过文字、节点压住图注
- [ ] **连线画出来了吗**？`.wires` 的 z-index 被内容层压住的话会整个不显示，且不报错
- [ ] 字号在**平台缩放到手机宽度**后还读得清吗？13.5px 是下限
- [ ] 图注有没有？**图内不含「图 N」编号**？

## 迁移旧图时（最容易出错）

- [ ] **旧图的每一行文字都搬过来了吗** —— 标题、副标题、每个方框里的字、说明句、图注
- [ ] 旧图里的**每个数值**都对上了吗
- [ ] 顺手核一遍**图里的数值和正文是否一致**。正文改了图没跟上，就是自相矛盾
- [ ] 旧图如果本身有错（数值错、内部代号），迁移时**顺手改掉**，
      不要照搬——旧图里的错误往往已经在正文里修正过了
- [ ] 用色语义对了吗？（蓝=本代 / 暖=对照方 / 红=代价，三者别混）

## 批量时

- [ ] 换底图或改配色后**重渲了全部**吗（`render.py --all`）
- [ ] 拼一张**总览图**扫一遍，看风格是否统一
- [ ] 如果分派了子 agent，**逐张验收**。子 agent 会漏内容、会重新引入已经修好的错误
- [ ] 配置里的**输出路径和文章引用一致**吗？写反了不报错，图会落到没人读的地方

## 文章层面

### 文件存在 ≠ 能显示

「文件在不在」这个检查是**不够的**。踩过两次，都是这个检查全绿但图就是显示不出来：

**坑一：扩展名与真实格式不符。** 从 PDF 导出图时，某些库（如 PyMuPDF 的 `Pixmap.save`）会**沿用 PDF 内嵌图的原始格式**，于是你可能拿到一个叫 `.png`、里面却装着 **JPEG2000** 的文件。文件在、大小正常、PIL 能打开——但 Chrome、知乎、微信**全都不支持 JPEG2000**，只有 Safari 认。必须验真实格式：

```python
from PIL import Image
import re, os
for md in <所有 .md>:
    for p in re.findall(r'\((figs/[^)]+)\)', open(md, encoding="utf-8").read()):
        im = Image.open(p)
        ext = os.path.splitext(p)[1].lower().lstrip(".")
        fmt = (im.format or "").lower()
        if not ((ext == "jpg" and fmt in ("jpeg","jpg")) or ext == fmt):
            print("不符:", p, "名为", ext, "实为", im.format)
```

对不上就重存：`Image.open(p).convert("RGB").save(p, "PNG")`。

**坑二：引用了素材目录。** 发布用的图必须放在**配图目录**里，不能引用 `_asset/` 这类工作目录——素材目录是放原图和处理中间件的，很多发布流程不认。这条要按目录白名单查，不是查文件在不在。

- [ ] 每张引用的图**真实格式与扩展名一致**（上面那段脚本）
- [ ] 每张引用都落在**配图目录**内，没有指到素材/工作目录
- [ ] 有没有**孤立的图**（生成了但文章没引用）？删掉或补引用
- [ ] 有没有**重复的图**（两次生成落到不同位置）？留一份
- [ ] 临时文件（`_test-*`、`_demo-*`、`_pick`、`_compare`）清理了吗

## AI 生成素材

- [ ] **逐张放大看过**，确认画面里**没有伪文字**（模型会自己长字，缩略图看不出来）
- [ ] 有没有哪张其实是 `Image blocked by safety filter` 的灰图混进来了
- [ ] 底图**亮度校准过**了吗（配图 30 / 意境图 24）
- [ ] 发表时的标注是「示意图 / 概念图」，**不是「摄影作品」**了吗
