# 交付前核对清单

配图这类东西，**代码不报错不等于图是对的**。下面每一条都是踩过的坑，逐条过。

## 单张图

渲染完 **Read 看一眼**，然后问：

- [ ] 有没有文字**溢出画布**或被裁掉？绝对定位的元素最容易出这事
- [ ] 有没有元素**重叠**？尤其连线穿过文字、节点压住图注
- [ ] **连线画出来了吗**？`.wires` 的 z-index 被内容层压住的话会整个不显示，且不报错
- [ ] 字号在**平台缩放到手机宽度**后还读得清吗？13.5px 是下限
- [ ] 图注有没有？**图内不含「图 N」编号**？

## 迁移旧图时（最容易出错）

- [ ] **旧图的每一行文字都搬过来了吗** —— 标题、副标题、每个方框里的字、说明句、图注
- [ ] 旧图里的**每个数值**都对上了吗
- [ ] 顺手核一遍**图里的数值和正文是否一致**。正文改了图没跟上，就是自相矛盾
- [ ] 旧图如果本身有错（数值错、内部代号），迁移时**顺手改掉**，
      不要照搬——旧图里的错误往往已经在正文里修正过了
- [ ] 用色语义对了吗？（蓝=本代 / 暖=对照方 / 红=代价，三者别混）

## 批量时

- [ ] 换底图或改配色后**重渲了全部**吗（`render.py --all`）
- [ ] 拼一张**总览图**扫一遍，看风格是否统一
- [ ] 如果分派了子 agent，**逐张验收**。子 agent 会漏内容、会重新引入已经修好的错误
- [ ] 配置里的**输出路径和文章引用一致**吗？写反了不报错，图会落到没人读的地方

## 文章层面

跑一遍，确认每张引用的图都真的存在：

```bash
cd <项目根>
for p in $(grep -ohE 'figs/[a-zA-Z0-9/_-]+\.png' *.md | sort -u); do
  [ -f "$p" ] || echo "缺 $p"
done
```

- [ ] 有没有**孤立的图**（生成了但文章没引用）？删掉或补引用
- [ ] 有没有**重复的图**（两次生成落到不同位置）？留一份
- [ ] 临时文件（`_test-*`、`_demo-*`、`_pick`、`_compare`）清理了吗

## AI 生成素材

- [ ] **逐张放大看过**，确认画面里**没有伪文字**（模型会自己长字，缩略图看不出来）
- [ ] 有没有哪张其实是 `Image blocked by safety filter` 的灰图混进来了
- [ ] 底图**亮度校准过**了吗（配图 30 / 意境图 24）
- [ ] 发表时的标注是「示意图 / 概念图」，**不是「摄影作品」**了吗

## 来源记录

- [ ] 厂商**内部代号**（项目代号、模块缩写）都换成了功能性描述
- [ ] 引用他人材料（厂商讲义、媒体图）的，**图注标了来源**，且保留了原图的会议标识
- [ ] CC0 / 公有领域素材的**出处记在案**（作者、来源、授权）
- [ ] 全部素材的来源整理进一份 `SOURCES.md` 之类的文档，别只存在脑子里
